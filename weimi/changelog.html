更新日志

只记录用户能感知的变化。更早的版本记录见 微密加密 App 更新日志。

v1.0.14最新

  • 新增在线《使用手册》：托盘右键与标题栏设置按钮右键都能直接打开「使用手册」「关于与诊断」，首次上手不必再翻旧文档。
  • 飞传文字消息改为气泡显示：单行文字只占一行，长文字按内容增高并在超过一屏时滚动查看，不再被时间戳顶成两行。
  • 修复飞传输入框右下角发送按钮点击无响应的问题，点击按钮与按回车都能发送。
  • 官网改版：以微密文件管理器为主展示，更新日志独立成页。
  • 修复地址栏和搜索框输入文字空白、选中内容不可见的问题，保持输入、中文输入法和深浅主题下的显示稳定。
  • 修复索引更新遇到异常父目录循环时可能卡住的问题；阻止无效目录关系写入，并恢复受影响磁盘的索引。
  • 改进索引服务安装与恢复：复用已运行的服务，等待正在停止的服务，设置超时并显示实际系统错误码。
  • 修正索引服务断开连接时的状态提示，避免将已安装的全机索引误报为用户模式。

v1.0.13

  • 修复原地重命名时输入框空白、文件名及选中态未显示的问题，保留扩展名并正确显示输入和鼠标选择结果。
  • 改进重命名提交与编辑器关闭：点击列表空白处提交，重复打开编辑器保持状态稳定，修复快速改名后退出可能卡住的问题。
  • 修复仅修改文件名大小写、非法名称与批量取消处理；同名目标不会被静默覆盖，已完成的改名仍可撤销。
  • 将重命名及新建失败提示改为顶部 toast，支持关闭、Esc、自动消失和悬停暂停；完善深浅主题、图标对齐及关闭按钮边距。
  • 感谢 Tao 在 PR #1 中提供原始调查与贡献；本版在此基础上整合了安全修复及定向验证。

v1.0.12

  • 新增「文件夹最近变化」，默认关闭。开启后记录运行期间的变化，显示近期时间标记并可查看新增、修改、移动和删除明细；普通浏览不显示追踪状态警告。
  • 修复移到回收站后未显示删除减号的问题，并改进摘要刷新和长名称布局。
  • 搜索和过滤结果高亮命中的文件名文字；过滤框支持一键清空，点击框外结束编辑，收回动画更利落。
  • 修复过滤后因保留旧滚动位置导致列表看起来空白的问题，包括 1# 等含符号名称。
  • 修复桌面文件夹快捷方式显示、新建文件重命名失焦、暂存区残留已删除文件及覆盖安装索引设置问题。
  • 改进空白处返回交互，降低误触；完善本次相关定向测试。

v1.0.11

预览体验

  • 详情栏预览下方新增折叠入口，可展开预览区域；记住折叠状态和详情栏宽度。
  • 图片支持滚轮缩放、按住左键平移，以及双击切换适应窗口与原始大小。
  • 文本和文档支持左键拖动浏览超出预览区域的内容，滚轮继续上下浏览。
  • 区分单击与拖动：超过系统拖动阈值才接管手势，PDF 预览器的翻页按钮仍可正常点击。
  • 切换文件、松开鼠标或取消操作后停止拖动，防止延迟事件继续移动内容。
  • 折叠栏箭头保持居中，过长文件名显示省略号；移除遮挡预览的拖动提示。

问题修复

  • 回收站仅列出当前用户且实际存在的回收项目，修复空回收站显示其他用户或残留记录的问题。
  • 修复侧栏滚动无法到底的问题，并支持拖动侧栏滚动条和点击轨道定位。
  • 「点击列表空白处回退」改为设置选项，默认关闭；搜索结果页始终不执行空白处回退。
  • 视频编码格式显示为 H.264、H.265 等可读名称，不再显示内部 GUID。

验证

  • 本地 933 项无截图回归、36 项预览点击与拖动测试通过。
  • 发布流程分别构建、测试 Windows 10 / 11 与 Windows 8.1 兼容版，并生成签名更新清单。
  • 文档预览由系统安装的预览器提供，拖动兼容性取决于预览器对标准滚动消息的支持。

v1.0.9

搜索体验

  • 搜索结果随输入即时更新，继续输入、删除文字时自动刷新。
  • 新增搜索历史，支持再次搜索、筛选历史、删除单条和清空记录。
  • 优化高级搜索布局、下拉选择、扩展名筛选和条件重置。
  • 支持 Ctrl+Tab / Ctrl+Shift+Tab 切换标签。

修复

  • 搜索结果页点击空白处不再回退，保留取消选择和框选操作。
  • 修复索引正常但部分文件无法被搜索到的问题；升级后旧索引会自动重建。
  • 修复搜索历史文字重叠、搜索范围菜单位置偏移的问题。
  • 输入框保留 LumaText 渲染，改为父窗口内的原生子控件，修复对话框关闭时残留输入框、闪烁及窗口层级异常。
  • 修复高级搜索中空输入框和输入框边缘无法点击的问题。

验证

  • 本地构建和独立回归测试通过，搜索及对话框修复已由用户实际试用确认。
  • 发布流程分别构建和验证 Windows 10 / 11 与 Windows 8.1 安装包，运行无截图回归测试。
