适用版本：1.0.14 及以上｜更新日期：2026-11-14

微密文件管理器（WeiMi，内核沿用 Pulse）是面向 Windows 的文件管理器：原生渲染、启动快、占用低，把多标签与多窗格浏览、全盘索引搜索、空格快速预览、暂存盘、飞传、保险箱放在同一个窗口里。

1. 安装与第一次打开

系统要求：Windows 11 / Windows 10（64 位）。另有 Windows 8.1 兼容版安装包。

  1. 运行安装包 WeiMiSetup-1.0.14.exe，按向导完成安装。
  2. 安装时可启用 PulseIndex 索引服务，用于全盘文件名与内容搜索；不启用也能正常浏览文件，只是搜索范围受限。
  3. 首次启动后可在「设置 → 启动与集成」里决定是否开机启动、启动时是否恢复上次的标签页。
  4. 界面提供简体中文、繁體中文、English，默认跟随 Windows 语言，可在「设置 → 显示语言」中切换。

3. 浏览与多窗格

  • 布局：Ctrl+1 单栏、Ctrl+2 左右分屏、Ctrl+3 上下分屏或三栏、Ctrl+4 四宫格。每个标签页独立记忆布局。
  • 视图切换：平铺、图标、列表、详细信息、内容。每个文件夹分别记住视图、排序和分组方式。
  • 分组与排序：按名称、日期、类型、大小分组；点击列标题排序，右键列标题可选择显示哪些列。
  • 标签页：Ctrl+T 新建，Ctrl+W 关闭，Ctrl+Tab 切换；标签页可拖出成独立窗口，也可竖排在侧栏（Ctrl+B 收起 / 展开侧栏）。
  • 文件夹对比：双栏打开两个文件夹，标出两侧不同、缺失和较新的项目；后台统计文件夹大小。

4. 找文件

  • 索引搜索：由 PulseIndex 服务维护全盘索引，结果随输入实时更新；可限定「当前文件夹」或指定文件夹。
  • 拼音搜索：支持全拼、首字母与多音字，例如输入 sh 即可找到「品牌设计」「城市夜景」等，命中文字会高亮。
  • 内容搜索：覆盖文本与代码、PDF、Word、Excel、PowerPoint 等格式，结果流式加载；打开所在位置后可后退回到结果列表。
  • 高级搜索：Ctrl+Shift+F 按类型、日期、大小等条件筛选。
  • 全局快速搜索：Alt+Space 随时呼出，可「在主界面搜索」查看全部结果。

5. 快速预览

选中文件按 空格 即可预览，不必打开对应软件：

  • Markdown 按排版显示，代码语法高亮，PDF 逐页翻看，文件夹显示内容列表。
  • CSV / TSV / XLSX 以表格显示；JSON / XML 显示为可折叠树；Jupyter Notebook 按单元格显示。
  • DOCX、EPUB 与 Office 文档无需安装 Office 即可阅读；压缩包显示目录树并可在包内搜索。
  • 视频可播放、拖动与逐帧；动态 WebP / APNG 可播放；支持 SVG、PSD、AI、DWG 缩略图与字体等格式。

指针在文件上停留片刻（默认 0.5 秒）会弹出悬停预览卡片，显示缩略图或文本摘录、类型与关键信息；卡片出现时按空格即展开为完整预览。「设置 → 快速预览」可改为仅空格预览，或调整悬停延迟与卡片尺寸。「支持的格式」一栏会检测 HEIF / HEVC / AV1 / WebP 系统扩展是否已安装。

6. 标签与收藏

  • 七种颜色标签可给文件和文件夹做标记，侧栏按标签汇总，也可按标签分组浏览。
  • 资源管理器右键菜单中同样可以打标签，与微密内保持一致。
  • 标签管理面板可重命名、改色、合并与清理失效标签。

7. 文件操作

  • 复制 / 剪切 / 粘贴：Ctrl+C / Ctrl+X / Ctrl+V；复制或剪切的项目会先进入暂存盘。
  • 拖放：默认复制，按住 Shift 为移动。
  • 新建与重命名：新建文件夹 / 文件；F2 重命名；多选后可批量重命名（支持序号、替换、正则）。
  • 删除：默认移入回收站；网络位置和可移动设备没有回收站，删除即不可恢复。
  • 压缩与解压：支持 ZIP 压缩与解压，可在包内浏览与搜索。
  • 文件被占用：提示占用进程，可结束进程后重试。
  • 磁盘信息：「此电脑」显示磁盘类型与容量条。

8. 暂存盘与文本对比

  • 复制或剪切的文件收进左下角暂存盘，可跨文件夹、跨标签页收集后一次拖到目标位置，也可「发送到设备」或一次打开全部项目。
  • 暂存两个文件时可对照位置、修改时间、大小与内容。
  • 文本文件点「查看差异」打开对比窗口：并排 / 统一视图、行内差异高亮、仅看差异、忽略空白与大小写，F7 / Shift+F7 在差异间跳转。

9. 飞传：电脑与手机互传

飞传让电脑与手机在同一局域网内直接互传文件与文字，不经过服务器。

准备

  1. 电脑与手机连接同一个 Wi-Fi；Windows 网络配置需允许「网络发现」（公用网络下默认不发现设备）。
  2. 手机端安装微密 App，或按电脑端提示用浏览器访问。

电脑 → 手机

  • 点标题栏的飞传按钮打开面板，面板会自动发现附近的微密设备；选择设备后发送文件。
  • 也可以把文件拖到托盘区的飞传区域（「飞传 · 拖到这里，选人后发送」），再选择接收人。
  • 暂存盘里的多个文件可一并发送：右键暂存盘 →「发送到设备…」。

手机 → 电脑

手机端选择电脑发送后，电脑端飞传面板会收到文件，可直接保存到当前文件夹。

文字互发

飞传面板底部输入框可直接发送文字，右下角按钮为发送键；消息以气泡显示，记录超过一屏时可滚动查看。

找不到设备时

  • 确认两端在同一网段，Windows 网络未被标记为「公用网络」。
  • 「设置 → 自动发现局域网设备」保持开启；必要时在「局域网发现设置…」中检查网络发现与防火墙。
  • 手机与 Windows 设备的配对提示需要点「允许」。

10. 保险箱与文件加密

微密提供两种隐私保护方式，密码均由 Windows 保护存储，只保存在本机。

保险箱

  • 第一次「加入保险箱…」时设置主密码；之后打开保险箱需输入该密码。
  • 右键文件 →「加入保险箱…」，文件加密后放入保险箱；保险箱位置可更改（箱内文件与主密码一并迁移）。
  • 主密码可更改；主密码丢失后箱内文件无法打开，请妥善保管。

单个文件加密

  • 右键 →「用微密加密…」，为所选文件设置密码，生成 .wemi 加密文件；可勾选「加密成功后删除原文件」。
  • 解密时输入加密时使用的密码；密码丢失后文件无法恢复。

11. 增强包

「设置 → 增强包」提供可选组件（如 ffmpeg 解码、图片格式、RAW、压缩包、AI 与 MCP 等），按需下载安装即可启用对应的预览或处理能力。

  • 点「下载并安装」，程序从官网增强包源直连下载并校验后安装。
  • 官网下载失败时，可在「增强包备用下载」（网盘）手动取得对应 .lzms 文件，放进 %LOCALAPPDATA%\weimi-desktop\packs\incoming\包名（如 ffmpeg、images、raw、archive），再回到本页点「下载并安装」离线安装。

12. 融入 Windows

  • 设为默认文件管理器：用于打开文件夹、Win+E 与桌面「此电脑」；「打开文件所在位置」会在微密中选中文件。随时可关闭，恢复原样。
  • 右键菜单：合并资源管理器与 Windows 11 新式菜单项（如 VS Code、Windows Terminal、NanaZip 等），微密自带项可隐藏。
  • 开机启动：可启动到托盘，并设置默认打开的文件夹。
  • 托盘：右键托盘图标可处理暂存盘项目、打开全部、定位到文件夹、对比、清空暂存区，以及「使用手册」与「关于与诊断」。
  • 设置按钮右键：在标题栏设置按钮上点右键，可直接打开设置、使用手册或关于页。

15. 自动更新

微密会在启动后自动检查新版，窗口内出现提示后点击即可下载安装包，校验通过后打开安装向导。也可在「设置 → 关于与诊断」手动检查更新；不想收到提醒时，在同一页关闭「自动检查更新」。

更新清单与安装包默认依次尝试加速源，连接失败自动切换，最后回退到 GitHub，无需设置；所有来源均须通过签名与安装包校验。1.0.14 起可在官网「更新日志」页查看每个版本的变化。

16. 常见问题

手机通过 USB 连上电脑却看不到？

解锁手机，下拉通知栏，点「USB 用于…」，选「文件传输」（有的手机叫「传输文件 / MTP」）；弹出「允许访问设备数据吗」时选「允许」；仍不行就换一根能传数据的线或换 USB 口，有些线只能充电。连好后会自动出现，不用刷新。

飞传看不到设备？

两端须在同一局域网；Windows 网络不能是「公用网络」；确认「设置 → 自动发现局域网设备」已开启；检查防火墙是否阻止了网络发现。

搜索没有结果？

确认 PulseIndex 索引服务已安装并完成首次索引；未建立索引时只能在当前文件夹内搜索。

预览是空白或提示缺少格式？

Office 等格式依赖增强包，按提示安装对应组件；HEIF / HEVC / AV1 / WebP 需要在系统安装对应扩展（「设置 → 快速预览 · 支持的格式」可检测）。

增强包下载失败？

多为网络或官网源不可达：改用「增强包备用下载」手动放包后离线安装（见第 11 节）。

忘记保险箱主密码或加密密码？

密码只保存在本机且不可找回，箱内文件与 .wemi 文件将无法打开，请另行备份并妥善保管密码。
